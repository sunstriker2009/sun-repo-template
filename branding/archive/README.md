# STRATA brand archive

The approved Earth & Sandstone panoramic raster and standalone reference image were generated during concept review. Their source image files have **not yet been committed** to this repository. SVG files under `branding/assets/` are new, simplified geometric adaptations, **not** pixel-identical vectorizations of the approved raster artwork. Do not describe them as original source artwork. Keep the original generated raster files intact when adding them to `branding/archive/originals/`.
